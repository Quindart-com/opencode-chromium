Keep your tools in step.

Published installations can update the local runtime to match the extension. Check Settings → Updates. Matching tools download in the background and switch after all browser sessions finish. Managed MCP connections stay open.

First time using automatic updates?Hide instructions

Run setup once from the current release:

npx -y opencode-chromium@latest setup --all

After current work finishes, reconnect MCP once to adopt the new updater. Development checkouts and pinned commands stay under your control. No browser or agent app is forcibly restarted.

Prefer fewer tabs? Turn off Show release notes after updates in the extension’s setup guide.
