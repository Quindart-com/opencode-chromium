## Scope and remaining limits

Native-host discovery and setup are implemented for Windows, macOS, and Linux; live browser runs above are Windows measurements. PR CI exercises build/package checks on all three platforms and real Firefox automation on Linux. Raw CDP, Chromium tracing, WebP screenshots, and unsupported Firefox environment emulation return explicit unsupported results. Inspection currently uses the top document; a cross-origin iframe inspection parity claim is not established. End-to-end Firefox consent-dialog upload, memory-replay, and multiple-profile coverage remain to be expanded beyond the backend/contract checks described above. AMO submission is distinct from approval and public availability.
