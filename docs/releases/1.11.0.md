# Version 1.11.0

- Install a version-independent controller and fixed host, MCP, and OpenCode launchers as the compatibility bridge from 1.10.x.
- Introduce schema-v2 runtime state, persistent controller jobs, per-connection leases, structured error codes, capability negotiation, rollback, and reconciliation.
- Report extension, global CLI, controller, desired runtime, active workers, and harness adapters independently. Treat the observed 1.10.2/1.10.1/staged-1.10.2 mismatch as reconcilable state rather than an old-CLI error.
- Route newly established connections to the desired release while existing initialized connections remain pinned until idle or disconnected. Never terminate active sessions for an update.
- Preserve the v1 four-tool contract and migrate legacy manifests, launchers, harness configuration, and semantic settings transactionally. Announce removal of granular tool aliases, legacy semantic aliases, and the shim package in 2.0.
