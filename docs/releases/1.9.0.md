# Version 1.9.0

Uploads now require a human decision in the extension by default. Each request shows the destination document, file names, sizes, optional raster previews and file locations; cancel, close, timeout, changed files or a changed destination attach nothing. Both file inputs and file drags pass through the gate, including direct CDP calls, and an agent's approval token cannot satisfy it. Updates and channel switches retain established replay memory, statistics, Jev settings, encrypted credentials, usage history and model-cache paths.

DeepSeek Harness (`dsh`) is a managed setup, update and uninstall target, including discovery, Windows version detection, `DSH_HOME` and custom profile paths. Cordis YAML edits preserve unrelated rows, comments, expressions, names and timeouts.

The agent cursor is rebuilt to match the Cua Driver cursor, ported from its MIT-licensed vector source: the same pointer silhouette with a white outline and glow halo, the same nine-colour per-session palette so concurrent agents are distinguishable, the same idle float, and the same trailing label pill with a two-second hold and fade. Twelve semantic action animations are driven by the tool or run step being executed, and clicks, hovers, typing, scrolling and drags glide the cursor onto the element they act on without blocking the action.

Page search is no longer dominated by the decision provider. The local retrieval result is authoritative and a paid decision is consulted only when that result is genuinely ambiguous, where it can only reorder candidates the local pipeline already found. Decisions are cached, coalesced and capped, and a decision whose query already matches exactly one candidate is skipped. Over a frozen 36-search fixture this took paid calls from 36 to 7 and median search latency from 450 ms to under 1 ms with unchanged accuracy; over eleven real tool calls against a local fixture page, total wall time fell from 4,423 ms to 1,767 ms. Failed and rejected steps now report a bounded message with one actionable hint instead of an observation and a repeated payload.

Package version 1.9.0. Publishing remains a single release: npm and the Chrome Web Store are updated by the same merge to `master`.
