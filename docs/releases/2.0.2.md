# Version 2.0.2

- Replace the non-working Update CLI action on older hosts with a copyable command that installs the current published runtime and controller, followed by a guarded bridge reconnect.
- Recognize current controllers without requiring legacy harness inventory, so a repaired installation no longer displays an incorrect update prompt.
- Keep major-upgrade approval actionable in both update views and preserve existing background updates for compatible installations.
- Add regression coverage for the 2.0.1 extension / 1.10.2 host mismatch, recovery controls, capability changes, and upgrade approval. Recovery instructions are available in all six supported languages.
