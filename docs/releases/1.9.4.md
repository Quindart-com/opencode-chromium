# Version 1.9.4

- Target same-origin and cross-origin embedded controls with `target.frameId`, including search, inspection, keyboard input and approved file uploads. Chromium child debugger sessions and Firefox BiDi contexts preserve the embedded parent page.
- Translate nested frame input through scrolling, borders and axis-aligned scaling, with ancestor obstruction checks. Rotated or perspective-transformed frames return `UNSUPPORTED_FRAME` for coordinate input.
- Keep node handles stable across observations and reject expired document handles before acting. Click checks distinguish lookalike overlays and support shadow-root hit testing.
- Focus keyboard-operable controls independently of editing. A targeted `press` focuses its control before sending the key; untargeted shortcuts use current focus and support ordinary page selection.
- Prefer the active dialog during inspection, report observation identity and capture time, and detect page changes during search ranking. DOM quiet requires a continuous 500 ms interval; an explicit settle condition remains the way to verify an application outcome.
- Report native-dialog state independently of event-history limits. Event reads and approved dialog recovery remain available while normal commands are blocked. Deadlines cover queueing and attachment; uncertain mutations are not automatically replayed.
- Finalize healthy tabs independently and report blocked tabs as partial cleanup, retaining their session for recovery. The extension distinguishes runtime connectivity from tab actionability.

These changes address reproducible causes and diagnostics from issues #43–#47. The original authenticated Google workflows still require report-specific confirmation; synthetic verification does not establish their exact original cause or resolution.
