# Version 2.0.6

## Features

- Experimental Ladybird support on Linux and Apple silicon macOS through its built-in WebDriver. The README covers setup, managed sessions and current limits.
- The Firefox read view handles deep pages and large multilingual responses, and element references click reliably (#77).
- With your approval for a specific tab, an agent can take over an existing tab safely. Background Chromium tabs accept input without being brought forward.
- Anonymous diagnostics help find unreliable tools. They contain no browsing content and can be turned off in **Settings → Anonymous diagnostics**. `opencode-chromium diagnostics summary` shows local failure details.
- The home screen shows whether each browser capability is available, with a short explanation.
- Shorter tool definitions and agent guidance use less context. Advanced options stay available on request.
- Targeted reads find exact offscreen labels and known record IDs.

## Bug fixes

- Reads recover after a completed action changes the page. Runs stop on access denials, rate limits and site challenges instead of retrying.
- Managed runtime updates are found automatically, and the extension reconnects after an upgrade finishes.
- Concurrent agents on Windows no longer lose replies while the runtime is busy.
- The upload switch no longer shows "off" while its setting is still loading.
- Decision assistance tells an exhausted OpenAI credit balance apart from a rate limit, and sends more compact requests.

## Maintenance

- Seeded browser verification in CI, plus verified browser action and reading benchmarks with frozen baselines.
- Release packages are scanned for private details before publishing.
- Groundwork for optional shared site reads. Nothing is shared, and the related settings stay hidden until a registry is available.
- Dependency updates and refreshed README badges.
