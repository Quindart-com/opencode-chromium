# Version 1.8.1

Fixes the blocked Jev setup flow: Settings now accepts a masked API key directly, tests authentication and a synthetic decision, then reports validity, timings, and available usage. Environment-variable configuration remains an advanced alternative. Overview shows actual Jev attempts, tokens, response times, and provider-reported cost. Unknown costs remain explicitly unreported.

The popup uses clearer headings, flatter surfaces, readable memory statistics, and collapsed local-model controls. Enabling a provider clearly describes its search/replay context; the misleading "Share page text" toggle is removed.

Exact replay is unchanged and requires no paid inference. For explicit memory intent, Jev can select a confirmed recipe within the current profile and site. Candidate revalidation, step matching, approvals, and mutation uncertainty remain enforced. Selection abstains below 0.95 confidence.

Normal tool responses retain `pluginVersion` and omit the static protocol/schema/capability fields and repeated plugin name. The native wire handshake retains its protocol compatibility check. Search decisions use smaller, deduplicated candidate context; singleton matches avoid a paid call. The four public tools and granular operations remain available.

This patch does not complete the full TypeScript migration or establish complete-flow Jev performance gains. The 1.8.0 local-model deprecation timeline and preserved databases remain unchanged.
