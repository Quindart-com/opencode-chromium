# 1.10.0

- Download extension-matched runtime releases while browser work continues, then activate at a verified idle boundary across all agents and registered profiles.
- Keep managed core MCP connections open while replacing versioned workers and reconnecting idle native hosts. A separate activation coordinator survives native host replacement.
- Track sessions, approvals, in-flight work and extension activity; paused agents and handoff tabs continue to block activation. Briefly queue new calls during the final switch.
- Retain previous workers during rollback, reconcile interrupted activation from the atomic runtime pointer and never replay uncertain browser mutations.
- Show selected, downloaded and loaded versions in the Updates panel. Contract incompatibilities explain when setup and reconnection are required.

Migration requires one `setup --all` run and MCP reconnection. OpenCode's native adapter participates in activity tracking; replacing its loaded adapter code still requires a reload. Explicit pins, development builds and standalone HTTP installations retain manual control.
