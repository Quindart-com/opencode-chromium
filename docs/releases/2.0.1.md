# 2.0.1

- Require explicit tab ownership: user-opened links, popups, and browser-created tabs no longer inherit an agent session from their opener.
- Keep review groups in their source windows and leave unrelated personal tabs untouched during finalization.
- Add Chrome lifecycle regression coverage for personal tabs, popup ownership, concurrent tab creation, and review across windows, plus an interactive native new-tab check.
- Update runtime dependencies and the pinned plugin security scanner together in one release.

Existing sessions retain their recorded ownership. Use `release-tab` to return a previously claimed tab to the user without closing it.
