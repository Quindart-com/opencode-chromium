# Version 1.8.0

This compatible release adds management and TypeScript foundations while preserving the four public tools, SDK exports, binary aliases, and granular operations.

- Selectable harness setup, explicit targets, configuration overrides, dry runs, file rollback, selected-client skills, and graceful restart choices.
- Checked compilation and declarations, compiled native-host distribution, untracked generated extension output, maintenance gates, and package smoke checks.
- Full-stack developer snapshot foundations with branch channels and isolated state. Extension reload remains manual.
- Experimental, explicitly enabled Jev text decisions through TypeSafe or OpenRouter, plus clearer popup provider controls. Luna remains unavailable preview support.
- Corrected transitive ZIP dependency pinning and safer build publication.

Embedded local models are deprecated starting with this release. They remain available while an optional legacy package is developed. Core memory databases and caches are preserved. Maintained legacy compatibility cannot end until a following major release and at least 90 days after the public deprecation release. No cache is deleted automatically.

The full rewrite, transactional browser registration inside setup, automatic developer-extension reload, optional legacy package, and coordinated public history cutover are unfinished. [Architecture status](../architecture.md) lists remaining work. This release does not claim complete live compatibility across every harness or faster complete browser flows from Jev.

To upgrade:

```sh
npm install -g opencode-chromium@1.8.0
opencode-chromium update --production --targets codex,opencode --json
```

Choose targets matching your installed clients. Reconnect terminal tools and reopen desktop clients after active work finishes. Store-installed extensions update through the browser after store publication; unpacked developer installations require reload.
