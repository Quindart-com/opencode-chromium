# Version 2.0.5

## Features

- Read pages as a compact, script-free text view (`browser_observe` mode `read`) with `[ref]` targets and change-only repeat reads, which cuts token use compared with screenshots.
- Act on read-view refs directly with `target { ref }`; each control is located again when the action runs.
- Background agent tabs keep rendering in place, so pointer input and screenshots work without bringing a tab forward and several agents can work in parallel.
- Leaner step results and token-saving guidance in the skill and server instructions.
- OpenCode 2.x support.

## Bug fixes

- Reliable automation on sites that block devtools or scripted pages: reads and input go through genuine pointer and keyboard events instead of page scripts, which avoids reload loops and blank-page redirects.
- Filling a field by ref now replaces its value instead of appending to it.
- Click points are correct on high-DPI displays.
- The popup keeps a typed profile label when the stored label loads late.

## Maintenance

- Dependency updates and a newer plugin security scanner action.
