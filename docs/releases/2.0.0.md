# Version 2.0.0

- Make the four high-level browser tools the complete public MCP surface. Remove granular public registration, deprecated command and test aliases, obsolete semantic strategy aliases, and the `opencode-chromium-mcp` shim package while retaining the canonical MCP bin.
- Activate releases blue-green per MCP connection and browser profile. New connections negotiate the desired contract; existing connections drain on their pinned worker. Rollback follows the same non-destructive path.
- Negotiate an extension wire contract independently of package versions. Older Web Store extensions remain on a compatible desired or fallback worker while a newer CLI/runtime is installed, and harmless version skew no longer blocks browsing.
- Validate package identity, metadata, entrypoints, and release hashes before desired-state changes. Retain desired and fallback releases, protect live leases, and collect older unleased releases only after seven days.
- Split the core runtime, browser operations, extension background, semantic search, and action-memory store into bounded modules. Enforce zero cycles, no reverse-layer imports, no architecture exceptions, and a 500-line production-file limit.
- Remove unused search wrappers and benchmarks, centralize product/runtime identities and shared helpers, optimize the Codex icon, consolidate operations documentation, and replace implementation-regex tests with behavioral contracts.
- Require explicit approval for major upgrades and expose persistent update, status, job, rollback, and reconciliation controls with sanitized component-level reporting.
