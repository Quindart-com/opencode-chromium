# Chrome Web Store listing translations

These descriptions are prepared for the Chrome Web Store dashboard. Select the matching locale after uploading a package containing that locale. Review screenshots and product claims before submission.

## 简体中文 (`zh_CN`)

将 OpenCode、Codex 和 MCP 智能体连接到您的浏览器。智能体可以搜索网页、填写表单、检查页面并截取屏幕，同时您仍可查看和控制操作。

安装扩展后，按照设置指南连接本地运行时。您可以为浏览器配置文件命名、查看连接状态，并选择是否启用决策辅助和本地操作记忆。文件上传默认需要确认；截图共享需要单独选择启用。

## Русский (`ru`)

Подключите OpenCode, Codex и агентов MCP к браузеру. Агенты смогут искать на страницах, заполнять формы, проверять содержимое и делать снимки экрана, пока вы сохраняете контроль над действиями.

После установки следуйте руководству, чтобы подключить локальную среду. Можно назвать профиль браузера, проверить состояние подключения и выбрать, включать ли помощь в принятии решений и локальную память действий. По умолчанию отправка файлов требует подтверждения; передача снимков экрана включается отдельно.

## Español (`es`)

Conecta OpenCode, Codex y agentes MCP a tu navegador. Los agentes pueden buscar en páginas, completar formularios, revisar contenido y hacer capturas de pantalla mientras mantienes el control de las acciones.

Después de instalar la extensión, sigue la guía para conectar el entorno local. Puedes nombrar el perfil del navegador, comprobar la conexión y elegir si activas la asistencia para decisiones y la memoria local de acciones. Las subidas de archivos requieren confirmación de forma predeterminada; compartir capturas se activa por separado.

## Português do Brasil (`pt_BR`)

Conecte OpenCode, Codex e agentes MCP ao seu navegador. Os agentes podem pesquisar páginas, preencher formulários, verificar conteúdo e capturar telas enquanto você mantém o controle das ações.

Após instalar a extensão, siga o guia para conectar o ambiente local. Você pode nomear o perfil do navegador, verificar a conexão e escolher se deseja ativar a assistência para decisões e a memória local de ações. Por padrão, o envio de arquivos exige confirmação; o compartilhamento de capturas de tela é ativado separadamente.

## Français (`fr`)

Connectez OpenCode, Codex et les agents MCP à votre navigateur. Les agents peuvent rechercher dans les pages, remplir des formulaires, vérifier leur contenu et faire des captures d’écran, tandis que vous gardez le contrôle des actions.

Après l’installation, suivez le guide pour connecter l’environnement local. Vous pouvez nommer le profil du navigateur, vérifier la connexion et choisir d’activer ou non l’aide à la décision et la mémoire locale des actions. Par défaut, l’envoi de fichiers demande une confirmation ; le partage des captures d’écran s’active séparément.
