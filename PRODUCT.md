# OpenCode Browser Plugin

Connect coding agents to a selected local browser profile through four compact tools: browser_run, browser_observe, browser_session, and browser_finalize. Adapters include MCP, OpenCode, and JavaScript SDK. The package and existing CLI aliases stay compatible.

The extension is an operating panel for connection health, named profiles, decision assistance, upload consent, and local action memory. Session ownership and live target validation govern automation. Upload confirmation is on by default. Cloud assistance is off by default; image sharing is an independent opt-in for Luna. Jev stays text-only.

## Approved popup direction

Compact professional panel with neutral surfaces, existing blue brand accent, system typography, clear spacing, and automatic light/dark themes. Overview prioritizes connection, selected decision model, memory status and relevant actions. Profiles retains selection, identity and labels. Settings retains decision assistance, uploads, memory controls and advanced local models. Timings, tokens, costs, identifiers and memory statistics remain accessible behind expandable sections.

The signature interaction is progressive disclosure: the default Overview stays quiet while detailed usage and memory controls open on demand. Keyboard tabs, visible focus, truthful loading/unavailable states, and narrow-width layouts are required.

Final light tokens: background #f4f7fb; surface #ffffff; text #111b2d; muted text #53657e; accent #3f63df; success #116d4e. Dark tokens: background #090f1d; surface #121c2e; text #f4f7ff; muted text #adc0dc; accent #86a6ff; success #56e5a8. CSS remains the source of truth for semantic variants.

No speed or accuracy claim is inferred from provider availability. Release verification distinguishes contract tests, browser fixtures, measured paid calls, unsupported capabilities and store review state.
