# opencode-chromium-mcp

Standalone `npx` entry for the [opencode-chromium](https://www.npmjs.com/package/opencode-chromium) MCP server.

This package is a thin launcher: it installs `opencode-chromium` and starts its
MCP server, so clients can register the server with a single short command:

```powershell
npx -y opencode-chromium-mcp
```

It is maintained in the [opencode-chromium repository](https://github.com/Quindart-com/opencode-chromium).
